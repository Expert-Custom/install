# Instaladores da ExpertCustom

Um arquivo por produto. Os scripts não guardam segredo: o token de acesso vai no comando.

## Framework

Linux e Mac:

```bash
curl -fsSL https://raw.githubusercontent.com/Expert-Custom/install/main/framework.sh | sh -s -- <token> <pasta-do-projeto>
```

Windows (PowerShell):

```powershell
iwr https://raw.githubusercontent.com/Expert-Custom/install/main/framework.ps1 -useb | iex
```
